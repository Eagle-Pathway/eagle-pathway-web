# Strict Agent Rules & Project Standards

## 1. Git & Deployment Workflow
- Always run `npm run build` after modifying code to verify that TypeScript and Next.js Turbopack compile with zero errors.
- NEVER run `git push` automatically. Always instruct the user to test locally first and only push after explicit user confirmation.

## 2. Navigation Sequence
- The navbar must always maintain this exact order:
  `Home` → `About` → `Services` → `Tutoring` → `How it works` → `Results` → `Apply with Us` → `Contact`

## 3. Link & Form Boundaries
- Never attach study abroad / scholarship Google Form links to Tutoring or other unrelated services.
- If a specific link is not provided by the user, use `href="#"` or direct hotline links.
